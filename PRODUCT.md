# Product context: Precision Intelligence Ledger

An editorial analytical workbench for students/researchers investigating an English social-media CSV. Primary task: ingest, analyze, understand change and inspect its supporting evidence. The user owns the selected dataset and run context.

Navigation: Dashboard, Datasets, Trends & Topics, Explorer, Analysis. Root redirects to Dashboard. Datasets is the starting point for custom input; the 900-post demo is a secondary reproducible walkthrough. Analysis retains academic methodology, model status, fixed settings, licensing and legitimate evaluation evidence for viva discussion.

The dashboard leads with ranked trends and actual reasons, followed by selected totals, temporal composition and entities/keywords/hashtags. Native selectors and URL parameters make every filter understandable and shareable. Topic detail separates full aggregates from representative samples. No fake LIVE/Pipeline Online states, development milestones or alpha messaging appear in the product.

Preserve the established light Ledger canvas, Space Grotesk headings, IBM Plex Sans body/UI, JetBrains Mono measurements, compact density, restrained semantic colors, one-pixel borders and small radii. Avoid gradients, glass, glow, decorative animation or invented metrics. Tables and a focusable SVG time series carry the analysis. See `DESIGN.md` for the design identity, `PRD.md` for current scope, and `docs/CODEX_AUDIT.md` for verification boundaries.
