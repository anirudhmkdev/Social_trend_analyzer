# Evaluation evidence and boundaries

The takeover audit found unsupported benchmark accuracy, throughput, phase completion and coverage claims in the previous documents. Those numbers have been removed. The current evidence is an executed regression suite, real API/UI integration with explicit inference fixtures, and separate local real-model smoke runs.

`backend/tests/model_fixtures.py` supplies deterministic inference only for integration tests. These tests verify contracts, scoping, orchestration, persistence and UI behavior; they do not measure RoBERTa accuracy, MiniLM semantics or spaCy accuracy. Missing-model and optional NER degradation tests exercise production failure/status behavior.

`backend/scripts/full_nlp_smoke.py` uploads a generated 90-row CSV once, previews/maps/validates/imports it, runs actual RoBERTa/MiniLM/BERTopic/spaCy and checks summary/timeline/topics/detail/Explorer/metadata. It separately loads/analyzes the 900-post demo. `docs/NLP_SMOKE_EVIDENCE.json` records inspected counts, sentiment, names/keywords, outliers, entities, classifications and method/status. Timings are observed on this one machine with existing model caches; they are not a throughput benchmark or performance guarantee.

The audited original developer database contained 1,535 posts, 136 non-outlier topics and 26 unclassified posts for its existing run. The corrected 900-post demo produced 25 non-outlier topics and 53 unclassified posts (5.89%). Dataset-relative sizing and one conservative semantic consolidation reduced fragmentation substantially. Family labels retain term descriptors and raw provenance instead of pretending the five generator themes are exactly five learned clusters. Templates still produce several subtopics; this remains an interpretation limit.

These counts compare different generator sizes, so they are not a controlled same-corpus coherence benchmark. The opt-in real-model browser checks also passed the complete CSV upload-to-Analysis path and the demo action with a new completed analysis. See the audit for executed test boundaries and timings.

The corrected real NER output prominently includes SEC, NBA, Meta AI, Microsoft, UEFA, Coinbase and named climate organizations. Hashtag-derived AITech/WorldCup lowercase person errors no longer dominate. Some spaCy errors remain: NFT may be assigned ORG and Paris Agreement may be assigned ORG. Entity predictions are model output, not an authoritative knowledge base. Sentiment on the real demo was 176 positive, 582 neutral, 142 negative; this is a distribution, not accuracy.

Sentiment evaluation utilities can compute accuracy, macro F1 and a confusion matrix only when independently supplied ground truth exists. The current upload mapping does not expose a sentiment ground-truth field, so ordinary uploaded CSVs and the bundled demo do not establish sentiment accuracy. Generator theme/pattern checks validate the synthetic source, not learned model labels. No NER precision/recall, general-topic coherence benchmark or external-dataset accuracy was measured here.
